🏦 Bank Microservices Project
📌 Overview
This project demonstrates a microservices-based architecture for a banking system. Each service is independently developed, deployed, and maintained, ensuring scalability and flexibility.

🧩 Microservices Breakdown
Service	Description	Database
Account	Manages customer account details	MongoDB
Loan	Handles loan operations and records	PostgreSQL
Card	Manages card issuance and transactions	PostgreSQL

🛠️ Tech Stack
Java / Spring Boot (assumed for service implementation)

MongoDB – NoSQL database for account service

PostgreSQL – Relational database for loan and card services

Docker & Docker Compose – For containerization and orchestration

Eureka / API Gateway (optional for service discovery and routing)

🚀 Getting Started
Prerequisites
Java 17+

Docker & Docker Compose

MongoDB & PostgreSQL (or use Docker containers)
